### 🧹 DataClean Pro v1.0.0

**Limpieza y automatización de datos | Data Cleaning & Automation**

Aplicación de escritorio para Windows que facilita la limpieza de archivos Excel y CSV y genera reportes estructurados.

**Características principales:**
- Importación de archivos Excel y CSV.
- Detección y eliminación de duplicados exactos.
- Identificación de celdas vacías.
- Limpieza de textos y encabezados.
- Generación de reportes Excel con cinco hojas.
- Estadísticas del procesamiento.
- Interfaz moderna y procesamiento independiente.
- Ejecutable para Windows con archivos de prueba incluidos.

**English:** A Windows desktop application built with Python to clean Excel and CSV files, identify duplicates and missing values, and generate structured reports.

**Tecnologías:** Python, Pandas, OpenPyXL, CustomTkinter, Pillow, PyInstaller.
